Rubah Ekor Sembilan di Bawah Bulan Merah — a majestic nine-tailed fox (kitsune) with nine flowing golden tails stands beneath a giant blood-red moon, cherry blossoms drifting through a starry night, a small shrine below. A single image entry for make.fun's "Make the AI judge excited" bounty. The artwork is held in the repository as `entry.png` — a rich, painterly image with soft glow, detailed fur and deep red-and-gold light — and `main.ts` (Node stdlib only) simply copies it to the output directory, so the judge sees exactly the bytes in the repo.

## Run it

```sh

```
